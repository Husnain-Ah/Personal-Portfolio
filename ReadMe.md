# Personal Portfolio

A modern React-based portfolio site built with Vite to showcase my skills, experience, and future projects while staying sharp on current front-end technologies.


## Purpose

- **Practise**: Experiment with React, modern tooling (Vite), and web technologies to keep skills current.
- **Showcase**: Display polished projects, demos, and links to source code repositories.
- **Connect**: Share my background, experience, and what I'm building next.


## Tech Stack

- **React 18** — Modern UI library for component-based development
- **React Router 6** — Client-side routing for navigation
- **Vite 4** — Fast, modern build tool and dev server
- **CSS** — Custom styling for a lightweight, no-framework design


## Project Structure

- `index.html` — Entry point for the application
- `src/main.jsx` — React application entry point
- `src/App.jsx` — Root React component with routing
- `src/ProjectPage.jsx` — Individual project detail page component
- `src/projectData.js` — Static data for future projects
- `src/styles.css` — Global styles
- `public/` — Static assets like profile images


## Features

- **Homepage**: Hero section, About Me with profile photo, and Future Projects grid
- **Project Pages**: Detailed views for each future project with back navigation
- **Responsive Design**: Mobile-friendly layout with custom CSS
- **Routing**: Client-side navigation between home and project pages


## Getting Started


### Prerequisites
- Node.js and npm installed


### Installation & Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser to `http://localhost:8888`


### Build for Production

```bash
npm run build
```

The optimized build will be in the `dist/` directory.
